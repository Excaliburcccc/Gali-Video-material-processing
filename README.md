# Gali Video Material Processing

Windows 本地游戏录像检索与 OBS 快捷标记工具。支持独立游戏方案和项目，内置《影之刃零》专用识别及可校准的通用文字提示方案。

## 适配其他游戏

1. 顶部点击“新建项目”，选择已有游戏方案，或选择“新建游戏方案”填写游戏名称与中文／英文。新周目可复用同一方案，新建独立项目。
2. 先导入一小段包含获得提示、任务完成等画面的录像，取消“导入后自动识别”。也保留背包、商店等负样例用于排除误报。
3. 在“识别设置”中打开“编辑游戏方案”。“分类与去重”设置栏目和每类重复处理方式；“提示规则”填写游戏实际出现的提示／类别标题，选择分类和事件含义。
4. 在“样例校准”中读取一帧，拖动框选提示区域及名称区域。选择不超过60秒的片段试识别；点击结果可跳转原录像核对。试识别不会写入正式素材库。
5. 保存方案后，再导入长录像或点击“开始识别”。修改分类和去重立即重新整理保留的原始记录；修改提示识别规则需要重新识别。相同源文件、画面位置和文字识别设置可复用本地文字缓存，新增区域或未扫描过的画面仍需识别。

“本项目只保留首次”按导入顺序、片内时间选取；“每次独立出现”合并同一次连续提示，保留下一次出现；“全部观察”保留逐次候选，供校准使用。人工修正或核实的记录保留。游戏之间、项目之间不相互去重，搜索、计数、时间轴及目录导出使用同一个项目范围。

方案每次保存产生新版本，当前项目使用保存后的版本，其他项目保留其原版本，已经排队的识别使用提交时冻结的方案。旧录像自动归入“影之刃零”项目；迁移不会修改或删除原片、标记和原始识别证据。

通用方案识别明确的文字提示，不会理解所有游戏动画。只有图标、声音、无字过场的事件仍需专用检测或手动标记。中文／英文共用现有本地OCR模型，不上传录像、不调用付费识别服务。

## 功能

- 地图收集：铃铛、武器及影之武装、饰品、药品、挑战地点、杀气琥珀碎片、黑石碎片、记忆之花。
- 任务：故事、异闻、收集。读物：书籍、记忆之花。另有剧情道具和 BOSS 分类，均支持名称搜索并跳转播放。剧情道具以物品面板中的类别与名称为依据，台词中提到的物品不单独收录。
- 默认只自动保留以上类目；不再收录普通字幕、教程和菜单说明。多文字界面保留有类别证据的当前标题，支持影之武装的武学、远程、破坏面板及地图选中铃铛；强化回退材料不进入目录。
- 左侧“全部事件”检索当前项目；点击单个录像只显示项目去重后属于该录像的记录。点击搜索结果会切换对应录像并定位，保留当前检索范围。
- 黑石碎片和杀气琥珀碎片保留每次记录；书籍排除菜单浏览，同一书籍及章节的连续弹窗合并，关闭后重新打开、不同章节及不同视频保留。其他同类同名对象按当前项目规则去重。各分类按录像导入顺序、片内时间排列。
- 记忆之花支持完整记忆及花瓣弹窗，保存花名和“其一、其二”等章节。不同花瓣分别保留，同花同章节的重复提示合并；菜单浏览不作为收集位置。地图收集和读物中的“记忆之花”入口都能查到两种记录。
- OBS 录制期间使用 `Ctrl+Alt+1/2/3/4` 添加收集、击败、成就和路线标记。
- 生成轻量预览，导出 H.264/AAC 片段供剪映导入，导出 CSV 事件目录。
- 勾选多个事件，可分别导出多个视频或按时间线合并为一个视频。时间戳前后秒数可统一设置或逐条调整，自动截到原片边界；跨录像按导入顺序排列。
- 使用本地 RapidOCR PP-OCRv3 / ONNX Runtime，不上传录像，不调用在线识别 API。

自动结果需要核实。首次看到不等于获得或击败；地图选中不等于激活传送点。当前规则针对演示中的 16:9 SDR 界面，正式版或其他界面需重新校准。

## 安装与启动

环境：Windows、64 位 Python 3.13（带 tkinter）、FFmpeg 与 ffprobe。将 FFmpeg 的 `bin` 目录加入 PATH。

所有项目、临时文件和可配置缓存默认放在 `E:\CodexFiles`。本机现有工作目录为 `E:\CodexFiles\影之刃零素材助手`。

```powershell
git clone https://github.com/Excaliburcccc/Gali-Video-material-processing.git E:\CodexFiles\Gali-Video-material-processing
Set-Location E:\CodexFiles\Gali-Video-material-processing
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

首次安装下载 Python 依赖；本地 OCR 模型随依赖安装。安装完成后双击 `启动素材助手.cmd`，访问 `http://127.0.0.1:8877`。运行 `setup.ps1 -CheckOnly` 可检查环境。退出后台服务使用 `停止素材助手.cmd`。

“识别设置”默认使用《影之刃零》指定类目识别，可调整采样间隔与识别宽度。完整操作说明见 [使用说明.txt](使用说明.txt)。

## OBS 连接

新安装不会自动修改 OBS。纯素材检索不要求连接 OBS。

1. 在本机 OBS 的 WebSocket 服务器设置中启用服务器和密码验证，默认端口 4455。
2. 复制 `config/obs-connection.example.json` 为 `data/obs-connection.json`，填入本机端口和密码。此文件已被 Git 排除，不要提交密码。
3. 先启动助手，再开始录制。正常结束录制后，录像与标记进入素材库。录制途中启动或重连无法保证计时，须从下一段开始使用快捷标记。

原有电脑的 OBS 配置、原片和索引继续保留。新机器需自行配置录制场景、编码、保存路径与声音；建议使用支持章节的录制格式，不启用自动分段。开始录制前选择对应项目。

## 文件与备份

| 内容 | 位置 | Git 同步 |
| --- | --- | --- |
| 后端与识别规则 | `app/` | 是 |
| 网页界面 | `static/` | 是 |
| 识别所需的小模板 | `app/assets/` | 是 |
| 测试源码 | `tests/test_*.py` | 是 |
| 本地索引、截图、OBS 连接与备份 | `data/` | 否 |
| 录像、导出片段 | `recordings/`、`exports/` | 否 |
| Python 环境与 OCR 模型 | `.venv/` | 否 |

仓库保存代码版本，不能替代录像和素材库备份。重要本地资料需另外备份；备份 SQLite 索引前先退出服务。

## 开发与测试

后续开发在本地 Git 项目中进行，修改后运行相应测试并保存本地版本。只有用户明确要求同步时才上传 GitHub；同步前检查远端，不上传运行数据，不强制覆盖远端历史。具体约定见 [AGENTS.md](AGENTS.md)。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

测试使用独立临时素材库，不接触真实索引。真实演示图片没有打包，依赖这些图片的测试会跳过；完整 OCR 合成录像测试可在本机设置 `RUN_OCR_INTEGRATION=1` 后运行。

项目监听本机地址。普通无文字击杀、过短的提示、未验证的成就界面和界面变化仍可能漏检，可用快捷标记补充。
